## Gemini API 收费标准与 Token 计算逻辑

不论你是通过官方还是中转平台调用，大模型 API 的计费核心都是 **Token**。
一段文本、一张图片、一段音频，在输入给模型时都会被折算成 Token。

Gemini 的计费分为两个主要部分：
1. **输入（Input Tokens）**：你发送给模型的提示词（Prompt）、历史对话、上传的图片或文档。
2. **输出（Output Tokens）**：模型生成并返回给你的回答。
*(注：通常输出 Token 的单价会高于输入 Token)*

### 1. Gemini 3.8 Flash 价格解析（主打性价比）
Flash 模型是目前市场上**性价比最高**的大模型之一。它的推理速度极快，且价格低廉，支持高达 100万 的上下文窗口。
*   **适用场景**：日常聊天、海量文本翻译、高频次的数据抽取、日志总结。
*   **价格感知**：处理几十万字的超长文档，或者几千次简单的 API 对话，通常只需要几毛钱到几块钱人民币，成本极低。

### 2. Gemini 3.8 Pro 价格解析（主打深度推理）
Pro 模型是 Google 的重型旗舰模型，对标 GPT-4o。
*   **适用场景**：复杂的代码生成与重构、深度数学推理、需要极高准确率的合同审查。
*   **价格感知**：单价比 Flash 贵数倍。因此，只有在 Flash 模型无法准确回答的“硬核”场景下，才推荐切换到 Pro 模型。

### 3. 多模态（图片/视频）如何计费？
Gemini 原生支持多模态。当你上传一张图片给 Gemini API 时，平台不会按“张”收费，而是**将图片转化为固定数量的 Input Tokens**（例如一张图片可能被折算为 258 个 Tokens）。
这意味着，发几张普通图片给 Gemini 分析，成本几乎可以忽略不计。

## 中转平台调用实战与消耗查看

当你在中转站充值获取了 `API Key` 和 `Base URL` 后，就可以直接在代码中调用并查看 Token 消耗。

以 Python 的 OpenAI SDK 为例：

```python
from openai import OpenAI

# 配置你的中转站信息
client = OpenAI(
    api_key="YOUR_PROXY_API_KEY", 
    base_url="https://your-api-domain.com/v1"
)

# 发起调用，指定 Gemini 模型
response = client.chat.completions.create(
    model="gemini-3.8-flash",
    messages=[
        {"role": "user", "content": "请用 100 字介绍 API 中转站的计费优势。"}
    ]
)

# 打印回答
print("模型回答:\n", response.choices[0].message.content)

# 打印本次调用的计费数据 (Token 消耗)
usage = response.usage
print("\n--- 计费数据 ---")
print(f"输入消耗 (Prompt Tokens): {usage.prompt_tokens}")
print(f"输出消耗 (Completion Tokens): {usage.completion_tokens}")
print(f"总计消耗 (Total Tokens): {usage.total_tokens}")
```

通过读取 `response.usage`，你可以精确统计每一次接口调用的消耗，从而在业务后端做好成本核算。

## 国内开发者如何降低 Gemini API 调用成本？

虽然中转站让调用变得容易，但合理的代码优化能帮你省下大量资金：

### 1. 合理使用 max_tokens
在请求时带上 `max_tokens` 参数（如 `max_tokens=500`）。这可以防止模型在发生“幻觉”时，写出长篇大论的废话，从而白白消耗高昂的输出 Token 费用。

### 2. 及时裁剪上下文
Gemini 支持百万上下文，但**历史聊天记录越多，每次提问的输入 Token 就越大**。
对于普通对话应用，建议在后端逻辑中只保留最近 5-10 轮的对话记录；或者当对话过长时，先让模型做一次“总结摘要”，用摘要替代漫长的历史记录。

### 3. 能用 Flash 绝不用 Pro
80% 的业务场景（如内容生成、网页摘要、简单闲聊、中英翻译）使用 `gemini-3.8-flash` 绰绰有余。只有在处理复杂的数学问题、逻辑推演或大规模项目代码生成时，才将其智能路由给 `gemini-3.8-pro`。

### 4. 结构化输出节省废话
如果你只需要模型提取数据，请在 Prompt 中强烈要求它**仅输出 JSON**：
`"请提取用户信息，严格输出 JSON 格式，不要包含任何额外的解释性文字。"`
少让模型说一句废话，就能多省下一分钱。
